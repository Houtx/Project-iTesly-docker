1. Overview

iTesly is a native TeslaMate companion app built to connect directly to your own self-hosted iTesly API proxy & TeslaMate server. iTesly follows a strict local-first, zero-tracking privacy model.

2. Data We Do Not Collect

TianZX Ltd. does not operate central user telemetry servers and does not collect, store, sell, or share:

  • Tesla account credentials or OAuth tokens (iTesly never prompts for or transmits your Tesla account password).
  • Vehicle location history, driving telemetry, charging records, battery metrics, or VIN identifiers from your self-hosted database.
  • Advertising identifiers, behavioral profiles, or third-party ad/analytics SDK data (zero ads, zero tracking SDKs).

3. Data Stored Locally on Device

  • Self-Hosted URL & API Token: Stored locally encrypted using Android Keystore (AES-256-GCM) and sent only to the self-hosted server address you enter.
  • Purchase Entitlement: Verified via Google Play Billing and cached encrypted on-device for offline access to Self-Hosted Mode.
  • UI & Display Preferences: Theme (Liquid Glass), map engine/tile style, coordinate conversion mode, language, and display units.

4. Third-Party Infrastructure & Billing

  • Google Play Billing: Optional one-time lifetime unlock purchases ($12.99 USD equivalent) are processed by Google Play. We never access your payment card information.
  • Map Tiles: Selected map views request public tiles (e.g., OpenStreetMap / Carto) using viewport tile coordinates only.
  • Optional Studio Artwork: Generic vehicle model/paint/wheel studio renders may load from Tesla's public configurator CDN without any VIN or personal identifier.

5. Demo Mode

Demo Mode works 100% locally using synthetic sample data without requiring any account or server.

6. Data Deletion

Tap Disconnect / Switch Server in Settings to wipe your saved URL and encrypted API token from Android Keystore immediately, or uninstall the app to remove all local state.

7. Contact

For privacy questions or app support, contact support@haoyunqiankun.com or visit https://github.com/Houtx/Project-iTesly-docker.
